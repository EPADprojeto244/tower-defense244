## TOWER-DEFENSE244

Um jogo Tower Defense desenvolvido com TypeScript, HTML, CSS e Canvas.

## Instalação

É necessário ter Node.js instalado.

Executa:

npm install

## Iniciar o jogo

npm run dev

## Criar versão de produção

npm run build

## Testes

npm test

## Funcionalidades

- Construção de torres
- Melhorias de torres
- Inimigos com diferentes atributos
- Sistema de ondas
- Sistema de ouro e vidas
- Vários mapas
- Guardar e carregar progresso
- Habilidades especiais
